서버 환경 변수로 PG 연결하기

아래 결제대행사 항목에 키를 등록하는 대신 호스팅 서비스의 환경 변수로 등록할 수도 있습니다. 환경 변수가 있으면 관리자 화면의 키보다 우선합니다. Vercel에서는 프로젝트의 Settings → Environment Variables에서 등록한 뒤 다시 배포하세요.

  • SHOP_TOSS_CLIENT_KEY, SHOP_TOSS_SECRET_KEY: 토스페이먼츠 키
  • SHOP_NICEPAY_TEST_MID, SHOP_NICEPAY_TEST_MERCHANT_KEY: NICEPAY 테스트 가맹점 키
  • SHOP_NICEPAY_MID, SHOP_NICEPAY_MERCHANT_KEY: NICEPAY 실결제 가맹점 키
  • SHOP_PAYMENT_PROVIDER=toss|nicepay: 사용할 PG 선택 (설정하면 아래 결제대행사 선택보다 우선)
  • SHOP_NICEPAY_RETURN_URL: NICEPAY 모바일/PC 복귀 URL (HTTPS)
  • SHOP_NICEPAY_SUCCESS_URL 또는 SHOP_NICEPAY_FRONTEND_URL: 승인 후 이동할 프런트 URL

토스는 테스트·실결제 키의 접두사가 다르므로 같은 모드끼리 등록하세요. NICEPAY는 MID와 MerchantKey를 같은 테스트/실결제 모드로 등록해야 하며, MerchantKey는 저장 후 다시 표시하지 않습니다.
