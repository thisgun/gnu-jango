아래 결제대행사 항목에 키를 등록하는 대신 호스팅 서비스의 환경 변수로 등록할 수도 있습니다. 환경 변수가 있으면 관리자 화면의 키보다 우선합니다. Vercel에서는 프로젝트의 Settings → Environment Variables에서 등록한 뒤 다시 배포하세요.

  • SHOP_TOSS_CLIENT_KEY: 토스페이먼츠 클라이언트 키
  • SHOP_TOSS_SECRET_KEY: 토스페이먼츠 시크릿 키
  • SHOP_PAYMENT_PROVIDER=toss: 토스페이먼츠 선택 (설정하면 아래 결제대행사 선택보다 우선)

테스트 키끼리 또는 실결제 키끼리 등록하세요. 클라이언트 키와 시크릿 키의 모드가 다르거나 키 형식이 맞지 않으면 결제 수단을 사용할 수 없습니다.
