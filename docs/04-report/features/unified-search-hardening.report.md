# 통합 검색 후속 개선

작성일: 2026-10-21

## 변경

- 공개 인기 검색어를 운영자 허용 목록과 최소 집계 횟수로 제한한다. 기본 목록은 비어 있다.
- DNT·실패·제한·민감 표현 검색 요청의 방문/검색 통계 기록을 생략한다. 기존 기록을 일괄 삭제하지 않는다.
- 페이지 범위를 보정하고 현재 페이지의 원문만 제한된 길이로 조회한다. 본문 권한을 다시 확인한다.
- 작은 묶음으로 새 색인 세대를 만들고 종류별 활성 포인터를 전환한다. 실패 시 기존 활성 색인을 유지한다.
- 클릭 보관기간 정리를 기존 예약 실행기에 연결하고 dry-run/JSON 출력을 지원한다.
- Vercel Preview에 별도 설정 프로필·DB 역할/스키마 검증·외부 연동 차단을 추가한다.
- 핸드북 검색 가이드와 배포 문서를 갱신한다.

## 운영 제약

색인 공간은 호환 문서 색인과 활성 스냅샷을 보존하므로 증가한다. 준비 중 세대가 있는 동안 추가 공간이 필요하다. 초기 마이그레이션은 새 코드를 배포하기 전에 적용하고, 새 버전이 반영된 뒤 세대를 재색인한다. 롤백할 때 새 테이블을 삭제할 필요는 없다.

Preview는 기존 Supabase 프로젝트의 자원을 공유한다. 역할에 운영 테이블 접근 권한이 없는지 확인했으며 운영 데이터는 복사하지 않는다. 임시 업로드는 영속적이지 않다. 같은 프로젝트의 여러 PR이 하나의 Preview 스키마를 공유하므로 마이그레이션을 동시에 적용하지 않는다.

실행 결과와 CI/배포 식별자는 완료 시 추가한다. 이전 기능 보고서의 테스트 수치는 이번 후속 변경에 대한 결과가 아니다.
