|---|---|---|

| S3 통합 API | 게시글·상품·내용관리/매뉴얼, 종류 필터·페이지·후보 제한·준비 상태 응답 | 완료 |
| S4 권한 | 검색 제외/비밀/등급/포인트/카테고리/판매/문서 공개 상태 검증, 순위에서 숨겨진 본문 제외 | 완료 |

| S8 기존 API | 기존 검색 preview 회귀, 상품 가격 정렬 유지, 미준비시 기존 검색 유지 | 완료 |
| S9 화면 | 기본/핸드북 테마 실제 브라우저, 상품 필터와 상품 상세 이동, 두 테마 빌드/동기화 통과 | 완료 |

9개 기능 요구사항이 구현되었다. 데이터 일관성 설계는 실제 Django 동작에 맞게 보완했다. 동기 signal의 문서/토큰 저장은 원자적이고, 외부 atomic 블록이 있을 때 원문과 함께 rollback된다. 자동 커밋 저장 이후 색인 실패는 재색인 복구가 필요하다.

대규모 실데이터 p95/디스크 사용량, 실제 Kiwi 바이너리를 설치한 환경의 재평가, 운영 배포는 이번 격리 검증에 포함하지 않는다. 합성 질문 평가를 실제 사용자 질문 품질로 일반화하지 않는다. 기존 그룹 검색 호환 API의 게시판별 순회는 유지되며, 새 기본 화면은 게시판 수와 무관한 통합 API를 사용한다.
