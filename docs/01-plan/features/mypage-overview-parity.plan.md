# 마이페이지 최근 활동 미리보기 계획

> 작성일: 2026-10-12 | 상태: 진행 중 | 구분: Dynamic

## 목적

원본 Gnuboard5/YoungCart `shop/mypage.php`가 제공하는 최근 주문내역과 최근 위시리스트를 Django가 제공하는 Next.js 마이페이지 대시보드에도 표시한다.

## 목표와 범위

- 최근 주문 5건을 주문일, 주문번호, 상품 수, 금액, 입금액, 미입금액, 상태와 함께 표시한다.
- 최근 위시리스트 8개를 상품 이미지·이름·가격으로 표시한다.
- 각 섹션에서 전체 주문 및 위시리스트 화면으로 이동할 수 있게 한다.
- 데이터가 없거나 로드에 실패한 상태를 구분해 안내한다.
- 관리자 화면, 주문 취소·결제 기능, 회원 프로필 편집은 범위에서 제외한다.

## 완료 기준

- 로그인 회원이 `/mypage`에서 최근 주문과 위시리스트 섹션을 볼 수 있다.
- 주문은 최대 5개, 위시리스트는 최대 8개로 제한되고 전체 목록 링크가 작동한다.
- 빈 상태와 API 오류 상태를 각각 확인할 수 있다.
- 새 Playwright 회귀 흐름 및 기존 필수 `django-flows.spec.ts` 5개가 통과한다.
- `npm run check`, `npm run build:theme`, Ruff, 마이그레이션 검사와 Django 전체 테스트가 통과한다.

## 근거와 위험

- 기준 화면: `C:\xampp824\www\gnuboard5_3\shop\mypage.php` 90–104행 및 `shop/orderinquiry.sub.php`.
- 현재 페이지에는 숫자 요약 카드만 있어 최근 주문과 위시리스트를 대시보드에서 바로 확인할 수 없다.
- 사용 중인 회원 전용 주문·위시리스트 API를 재사용해 스키마 변경을 피한다.
- 배송지·개인정보는 대시보드에 추가 노출하지 않는다.
