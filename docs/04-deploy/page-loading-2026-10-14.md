## 확인 결과

- 홈·쇼핑몰: 데스크톱과 모바일에서 HTTP 200, 통합 API 각각 1회, 가로 넘침·처리되지 않은 JavaScript 오류·페이지 자산 HTTP 오류 없음.
- `/api/v1/status`, `/api/v1/home`, `/api/v1/shop/home`: HTTP 200, 성공 응답 및 프론트엔드 데이터 형식 확인.
- 통합 API의 `Cache-Control`: `no-store, private`.
- 폰트: 배포 파일의 SHA-256이 커밋한 원본과 일치.
- 샘플 배너: HTTP 200, 브라우저 캐시 1시간, 반복 요청의 `X-Vercel-Cache: HIT` 확인.
- `/admin/login/?next=/admin/`: HTTP 200.
- `/admin/sample-data/`: 비로그인 상태에서 관리자 로그인 화면으로 이동. 관리자 계정으로 샘플 추가·삭제하는 작업은 실행하지 않았다.
- Django 회귀 검사 73개, Playwright 9개, 타입·린트·테마 빌드·정적 자산 동기화 검사 통과.

### 기존 데이터·권한 상태

- 운영 쇼핑몰의 각 메인 상품 유형 조회 결과는 변경 전·후 모두 0개다. 카테고리 1개와 배너 1개는 표시된다. 상품 데이터의 추가나 노출 설정 변경은 이번 배포에 포함되지 않는다.
- 첫 홈 게시글의 상세 HTML은 200이지만, 자유게시판의 읽기 포인트가 `-1`이어서 비로그인 상세 API는 기존 `insufficient_points` 403을 반환한다. 이를 페이지 장애나 새로운 404로 처리하지 않았으며 읽기 권한 규칙을 유지했다.
